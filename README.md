# SANTALIQ

**Santali Language. AI Innovation.**

SANTALIQ is a digital home for the Santali language, people and culture — language tools, grounded AI, voice, learning, heritage and community, built Santali-first and multi-script (Ol Chiki · Bengali · Devanagari · Odia · Roman).

> Status: Phase 0 — project setup. Nothing is deployed yet.

## Repository layout

| Folder | Purpose |
| --- | --- |
| `frontend/` | Next.js + TypeScript + Tailwind CSS web app |
| `backend/` | Python FastAPI modular monolith |
| `infrastructure/` | Docker, Nginx, deployment and monitoring config |
| `scripts/` | Developer utility scripts |
| `docs/` | Plans, architecture, decisions and progress |
