# Interface languages (English | বাংলা)

**Status:** v1. The EN | বাংলা switch is in the header, the mobile menu and the footer. The choice is remembered in the browser. The first visit picks Bengali if the browser language is Bengali.

## How it works
- `frontend/src/lib/i18n/messages.ts` holds the `en` and `bn` dictionaries. `bn` is typed as `Messages`, and a unit test checks that both have the same keys and placeholders and that no Bengali text is empty.
- Client components use `const t = useT()`, then `t.section.key`; `fill(t.x, { lang })` fills `{placeholders}`.
- Server components (pages that export `metadata`) render `<T k="section.key" />`. The server always renders English, so search engines index English, and the browser switches right after load.
- `localeInitScript` sets `<html lang>` before paint.

## Not translated (on purpose)
- The admin dashboard: internal and English for now.
- Privacy and Terms: an official Bengali version will come after legal review.
- Content written by members, and all Santali text.

## Rules
- Only interface text is translated. **Santali words, examples and cultural content are never machine-translated or invented.**
- An Ol Chiki / Santali interface needs translations from native speakers. Add a `sat` dictionary when one is provided.
